# Nusra Tax & Notary — AI Search Visibility & SEO Audit

**Audit date:** 2026-08-22  
**Production URL audited:** `https://www.nusrany.com`  
**Method:** Read-only HTTP fetches of production public URLs, source-code inspection, and repository documentation review. No search rankings, traffic estimates, or visibility scores are inferred.

## Executive summary

### Verified strengths

- Production `sitemap.xml` currently uses `https://www.nusrany.com`.
- Production `robots.txt` currently references `https://www.nusrany.com/sitemap.xml`.
- The live sitemap contains no observed `vercel.app` URLs.
- Privacy, terms, and disclaimer entries currently use priority `0.3` and `yearly` change frequency.
- The live sitemap contains published service URLs and no empty blog-category URLs were observed.
- Public pages consistently present the current primary entity as **Nusra Tax & Notary**, operated by **Nusra Trading Inc.**
- The live homepage, About page, Team page, and service content clearly expose Queens/Hollis location, languages, owner information, services, and credentials.
- Reviews shown on the homepage include service descriptions and `View on Google` links; no placeholder review state was observed on the live homepage.

### Verified issues

1. Office hours are inconsistent: the live header and office section say **“Call for current availability”**, while the live FAQ says **Monday through Friday, 11:30 AM to 5:30 PM**, and the repository verification sheet marks those hours as confirmed.
2. Current JSON-LD emits only `LocalBusiness` for the homepage and `Service` for service pages. No `Organization` or owner `Person` JSON-LD was found in the source implementation.
3. The current `LocalBusiness` JSON-LD omits the legal entity, opening hours, area served, languages, logo/image, and verified social profiles.
4. `buildMetadata` does not emit Twitter metadata. OpenGraph is only created when a page has an image, so pages without CMS images do not receive an explicit OpenGraph object from this helper.
5. The confirmed public person entity is **Aminul Islam Khan**, CEO of **Nusra Trading Inc.** Internal verification documentation has been normalized to this public name.
6. Blog category pages are technically handled with `noindex` when empty, but the blog index still renders every CMS category without filtering out categories that have zero published posts.
7. External listing consistency could not be verified from the available read-only access. Google Search/Maps did not expose a usable listing payload, Yelp returned a JavaScript/anti-bot response, and Facebook returned 404. These are unverified, not confirmed missing listings.

Verified results:

| Check | Finding | Evidence |
|---|---|---|

| Vercel URLs | None observed | Live sitemap fetch contained no `vercel.app` URL |

**Remaining verification limitation:** a public sitemap does not expose whether a CMS date is semantically correct; it only exposes the resulting value. The source implementation now avoids deployment timestamps, but CMS records should still be reviewed for inaccurate manually entered dates.
